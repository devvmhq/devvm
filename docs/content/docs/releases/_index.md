Each release has a page here with the full story of every change it makes: what was wrong or missing, how it showed, how devvm now works, and what you do about it. The changelog on GitHub, which is each release's notes, keeps one or two sentences for each change, with a link to its section here, its issue and the commit that made it.

- [0.2.0](0.2.0.md): VMs' ssh on ports that browsers refuse, the proxy split into two processes with a sandbox around the one that reads the VM's network, Claude Code's plugins and MCP servers' logins in a VM, project folders after your Mac restarts, status lines for slow steps, and many hardening fixes.

These are the one part of the docs that describes what changed. Every other page describes how devvm works now.
